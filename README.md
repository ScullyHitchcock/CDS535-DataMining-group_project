# Data Mining Experiments on Diabetes and Heart-statlog

This project includes three experiments: the effect of standardization on k-NN, a comparison of four classifiers, and K-means clustering on the diabetes dataset.

## Running the Notebook

**macOS / Linux：**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m notebook
```

**Windows**

```bat
py -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python -m notebook
```
